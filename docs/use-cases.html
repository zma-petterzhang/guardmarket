commerce.cart_total

购物车结算 / Cart total

将购物清单、优惠百分比、税率和运费作为输入，获得可复核的结算金额。税率来自调用方。

输入

{
  "items": [
    {
      "sku": "A",
      "unit_price": "10.00",
      "quantity": 2
    }
  ],
  "discount_percent": 10,
  "tax_percent": 5,
  "shipping": "3.00"
}

预期输出

{
  "lines": [
    {
      "sku": "A",
      "quantity": 2,
      "line_total": "20.00"
    }
  ],
  "subtotal": "20.00",
  "discount": "2.00",
  "taxable": "18.00",
  "tax": "0.90",
  "shipping": "3.00",
  "total": "21.90"
}

csv.escape_formulas

导出前处理 CSV / Spreadsheet-safe export

对用户提供的 CSV 数据执行公式转义。检查返回内容后再交给电子表格；该技能不读取或上传本机文件。

输入

{
  "rows": [
    [
      "name",
      "value"
    ],
    [
      "item",
      "=1+1"
    ]
  ]
}

预期输出

[
  [
    "name",
    "value"
  ],
  [
    "item",
    "'=1+1"
  ]
]

inventory.reorder_point

库存补货规划 / Reorder point

根据提供的需求与交付时间数据计算补货阈值。计算不会修改店铺库存或自动采购。

输入

{
  "on_hand": 20,
  "on_order": 0,
  "reserved": 5,
  "daily_demand": 4,
  "lead_days": 5,
  "safety_stock": 10
}

预期输出

{
  "reorder_point": 30,
  "inventory_position": 15,
  "reorder_needed": true,
  "suggested_quantity": 15
}
