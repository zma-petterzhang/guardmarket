commerce.volumetric_weight

包裹体积重

Calculate L×W×H/divisor from centimetre dimensions; caller supplies the carrier's divisor and actual kilograms.

Version 1.0.0确定性数据处理Backend required

使用场景 / Purpose

Commerce: volumetric weight. 本技能对提供的参数执行计算，输入输出契约如下。文档例子来自已实现函数的固定验收样例；网页本身不执行代码。

输入字段 / Parameters

字段类型要求约束与说明
length_cm"number"必填 Required{"minimum": 0, "maximum": 10000}
width_cm"number"必填 Required{"minimum": 0, "maximum": 10000}
height_cm"number"必填 Required{"minimum": 0, "maximum": 10000}
divisor"number"必填 Required{"minimum": 1, "maximum": 10000}
actual_kg"number"必填 Required{"minimum": 0, "maximum": 100000}

输入例子 / Example input

{
  "length_cm": 50,
  "width_cm": 40,
  "height_cm": 30,
  "divisor": 5000,
  "actual_kg": 8
}

预期输出 / Expected output

{
  "volumetric_kg": 12.0,
  "chargeable_kg": 12.0
}
