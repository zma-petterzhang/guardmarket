inventory.reorder_point

计算补货点

Use demand×lead time+safety stock, rounded up; compare with on-hand+on-order-reserved inventory position.

Version 1.0.0确定性数据处理Backend required

使用场景 / Purpose

Inventory: reorder point. 本技能对提供的参数执行计算，输入输出契约如下。文档例子来自已实现函数的固定验收样例；网页本身不执行代码。

字段类型要求约束与说明
on_hand"integer"必填 Required{"minimum": 0, "maximum": 1000000}
on_order"integer"必填 Required{"minimum": 0, "maximum": 1000000}
reserved"integer"必填 Required{"minimum": 0, "maximum": 1000000}
daily_demand"number"必填 Required{"minimum": 0, "maximum": 100000}
